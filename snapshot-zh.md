      - generic [ref=e295]:
        - paragraph [ref=e296]:
          - text: 安全门在

    - region [ref=e299]:
      - generic [ref=e300]:
        - paragraph [ref=e301]: 硬边界
        - heading "真实操作有边界" [level=2] [ref=e302]
        - paragraph [ref=e303]: 每个写操作都走同一条强制路径：读操作保持高效，真实变更始终明确且可复核。
      - generic [ref=e304]:
        - article [ref=e305]:
          - heading "预检 Preview" [level=3] [ref=e309]
          - paragraph [ref=e310]: 执行前看到目标、参数、影响范围和风险，明确将要改变什么。
        - article [ref=e311]:
          - heading "用户审批 Approve" [level=3] [ref=e315]
          - paragraph [ref=e316]: 受保护的运行态写操作等待明确决定；没有批准，就没有变更。
        - article [ref=e317]:
          - heading "一次性令牌 One-time Token" [level=3] [ref=e321]
          - paragraph [ref=e322]: 短期令牌只绑定已批准的具体操作，不能换目标或重复使用。
          - code [ref=e324]: "token: sd_eyJhbGciOiJIUzI1Ni... scope: restart_service expires_in: 60"
        - article [ref=e325]:
          - heading "审计记录 Audit" [level=3] [ref=e329]
          - paragraph [ref=e330]: 预检、批准、执行、结果和上下文在操作结束后仍然可追溯。

            - code [ref=e332]: 10:24:05 preview restart_service
            - code [ref=e333]: 10:24:06 approved user@macOS
            - code [ref=e334]: 10:24:18 success pid=9488
      - paragraph [ref=e335]: 所有安全约束都由 local agent 强制执行；没有静默写入，也不依赖提示词自觉。
